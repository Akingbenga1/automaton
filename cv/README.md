# CV Directory

Place your CV/resume PDF files in this directory.

## Current CVs

- Gbenga Akinbami Base Tech CV.pdf

## Adding More CVs

You can create multiple CV variants for different types of roles:

- `technical_lead.pdf` - For technical leadership roles
- `engineering_manager.pdf` - For management positions
- `product_manager.pdf` - For product management roles
- `generic.pdf` - General purpose CV

## Configuration

Update the CV path in `config/profile.yaml`:

```yaml
cv:
  default_path: "cv/Gbenga Akinbami Base Tech CV.pdf"
```

## Tips

- Keep CVs under 2MB for easy uploads
- Use PDF format for best compatibility
- Update CVs regularly to reflect new skills and experience
- Tailor CVs for different role types when possible
